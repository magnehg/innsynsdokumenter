# Øvingshefte A – Ankerfjorden kommune

De 30 dokumentene fra øvingshefte A (innsynsbehandling, versjon 1.1), én PDF per dokument.
`oversikt.csv` viser nummer, filnavn, dato, tittel, saken dokumentet hører til og siden i heftet.

Hele heftet, med forside, omtale av kommunen, oppgaver og dokumentoversikt, ligger i
[`samlet/Ovingshefte_A_innsyn_FIKTIV_v1.1.pdf`](../../samlet/Ovingshefte_A_innsyn_FIKTIV_v1.1.pdf).

Alt i én zip: [ovingshefte-a-ankerfjorden.zip](https://github.com/magnehg/innsynsdokumenter/raw/main/zip/ovingshefte-a-ankerfjorden.zip).

Ankerfjorden kommune og alt innholdet er oppdiktet. Lisens: CC BY-SA 4.0, se [README](../../README.md) i rota.
