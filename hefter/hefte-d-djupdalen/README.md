# Øvingshefte D – Djupdalen kommune

De 30 dokumentene fra øvingshefte D (innsynsbehandling, versjon 1.1), én PDF per dokument.
`oversikt.csv` viser nummer, filnavn, dato, tittel, saken dokumentet hører til og siden i heftet.

Hele heftet, med forside, omtale av kommunen, oppgaver og dokumentoversikt, ligger i
[`samlet/Ovingshefte_D_innsyn_FIKTIV_v1.1.pdf`](../../samlet/Ovingshefte_D_innsyn_FIKTIV_v1.1.pdf).

Alt i én zip: [ovingshefte-d-djupdalen.zip](https://github.com/magnehg/innsynsdokumenter/raw/main/zip/ovingshefte-d-djupdalen.zip).

Djupdalen kommune og alt innholdet er oppdiktet. Lisens: CC BY-SA 4.0, se [README](../../README.md) i rota.
