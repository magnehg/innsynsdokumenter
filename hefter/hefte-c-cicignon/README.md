# Øvingshefte C – Cicignon kommune

De 30 dokumentene fra øvingshefte C (innsynsbehandling, versjon 1.1), én PDF per dokument.
`oversikt.csv` viser nummer, filnavn, dato, tittel, saken dokumentet hører til og siden i heftet.

Hele heftet, med forside, omtale av kommunen, oppgaver og dokumentoversikt, ligger i
[`samlet/Ovingshefte_C_innsyn_FIKTIV_v1.1.pdf`](../../samlet/Ovingshefte_C_innsyn_FIKTIV_v1.1.pdf).

Cicignon kommune og alt innholdet er oppdiktet. Lisens: CC BY-SA 4.0, se [README](../../README.md) i rota.
