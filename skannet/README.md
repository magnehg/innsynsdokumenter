# Den skannede utgaven

De samme 615 dokumentene i dårlig kvalitet: skannet, fotografert, kopiert på kopimaskin og fakset (PDF, JPG, PNG og TIF).
En fjerdedel av brevene er håndskrevet med varierende tydelighet, og en del har for lav kontrast.
`oversikt.csv` viser per fil om den er håndskrevet, om kontrasten er lav, hvordan den er tatt opp, oppløsningen,
antall sider og (for SMS-ene) dialekten eller språkformen.
